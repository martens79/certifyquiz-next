# Space Grotesk

Vendored from the official Google Fonts repository:
https://github.com/google/fonts/tree/main/ofl/spacegrotesk

`SpaceGrotesk-Variable.ttf` is the upstream `SpaceGrotesk[wght].ttf`,
downloaded 2026-10-20. SHA-256:
`acad6de1fc93436f5c0f1f4137751ef04f1aea3063e7036535970ffcfbd79f72`.

The SIL Open Font License is included in `SpaceGrotesk-OFL.txt`.
The four localized business pages share one `next/font/local` definition.
This avoids the Google CSS URL parsing failure observed in the R07 Vercel
build while preserving the font family and the `--font-display` variable.
