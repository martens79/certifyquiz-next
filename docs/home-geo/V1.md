Existing certPath defines canonical localized paths (EN without prefix). No bot-specific content, redirects, GPS or external geolocation. Search engines may index general suggestions; country variants are optional UI, not SEO landing pages. Fixed two-card structure and minimum dimensions reduce shift; visual and CLS verification remains required. Initial general suggestions may briefly precede restored preference. No geography in URL or server cache keys. Do not call this automatic geolocation.

## Measurement
Uses existing consent-gated trackEvent, no funnel DB calls. home_geo_impression after preference restore and >=50% section intersection; home_geo_clicked on native anchor click; home_geo_country_changed on manual change. Payload: selected country (editorial preference, not verified location), language, certification slug(s), source_page=home. Impression re-arms on country/language change; no events before explicit analytics consent. A consent grant while section remains visible may undercount an earlier impression; no retrospective tracking. Evaluate clicks/impressions by country selection and cert; low traffic does not justify causal conversion claims. GA4 custom dimension registration is a separate admin task, not performed.
