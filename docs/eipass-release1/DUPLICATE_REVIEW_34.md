## Gate per una futura decisione

Acquisire chiavi e spiegazioni, confrontare quattro lingue, frequenza d’uso e progressi salvati; decidere per coppia KEEP_BOTH / DIFFERENTIATE / CONSOLIDATE_LATER. Per questa release lo stato è KEEP_BOTH_PENDING_REVIEW per tutte le34 coppie. Ogni consolidamento futuro richiede alias o compatibilità per ID storici, piano reversibile e autorizzazione separata.
